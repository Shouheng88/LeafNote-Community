:name> common_app_intro_detail_2
:text> OneDrive、DropBox、CloudFlare R2、Git、百度網盤、WebDAV、および外部ストレージディレクトリの7種類の同期方式をサポート。ノートの変更は即座にサーバーに同期されます。

:name> set_sync_server_choose
:text> 選択

:name> sync_server_webdav_desc
:text> WebDAV プロトコルによる同期をサポートし、Nextcloud、ownCloud、Synology NAS など、さまざまなクラウドストレージサービスと互換性があります。

:name> sync_server_dropbox_desc
:text> Dropbox にノートを同期します。Dropbox アカウントにログインして承認するだけで使用できます。

:name> sync_server_onedrive_desc
:text> ノートをOneDrive（個人アカウント）に同期します。Microsoftアカウントにログインし、権限を付与するだけで使用できます。

:name> sync_server_baidu_desc
:text> ノートを百度ネットディスクに同期します。

:name> sync_server_cloudflare_r2_desc
:text> Cloudflare R2 オブジェクトストレージを通じた同期（S3 互換 API を使用）、アカウント ID およびアクセスキーの入力が必要です。

:name> sync_server_git_desc
:text> ノートをリモートの Git リポジトリに同期し、完全なコミット履歴を保持します。ただし、単一のノートを個別に同期することは現時点ではサポートされていません。

:name> sync_server_external_storage_desc
:text> ノートをローカルの外部ストレージディレクトリに同期します。ネットワーク接続は不要で、USBメモリやSDカードによるバックアップに適しています。

:name> config_new_version_default_desc
:text> アプリケーションの詳細を最適化しました。
